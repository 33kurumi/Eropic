> 目标：在 Android Studio 里生成 Eropic 的 Kotlin + Jetpack Compose 工程骨架，作为后续所有开发的基础。
> 适用：Windows + Android Studio 2025.2.2 + JDK 17 + Android SDK 36（当前机器实测）

## 2. 先定这 8 个决策（一次选对，避免返工）

| 决策 | 选择 | 原因 |
|---|---|---|
| 模板 | **Empty Activity**（Compose） | 不要选 "Empty Views Activity"（XML 那套） |
| 语言 | Kotlin | Compose 仅 Kotlin |
| 构建脚本 | Kotlin DSL（`build.gradle.kts`）+ Version Catalog | AS 默认，官方推荐 |
| minSdk | **31（Android 12）** | 你的要求；同时避开 Android 11 分区存储老坑 |
| compileSdk / targetSdk | **36 / 36** | 已安装；注意 targetSdk ≥ 35 在 Android 15 上强制 edge-to-edge，UI 必须处理 insets |
| 包名 | `io.github.<GitHub用户名>.eropic` | 开源惯例；用户名含 `-` 用 `com.eropic.app`；现在定，发布后改代价大 |
| 模块 | 单模块 `:app` | 见 ADR-0001；M2 后再评估拆分 |
| 分发 | GitHub 开源 + 侧载，不上架 | 权限路线：M0 只读最小权限，M3 再定写权限（ADR-0002） |

## 3. 解决"目录非空"（重要）

新建向导要求 Save location 是空目录，而仓库里已有 `README.md` 和 `docs/`。

### 方案 A：临时移走文档（推荐）

先确认目录内容，再移走：

```powershell
Get-ChildItem D:\Github\Project\Eropic
Move-Item D:\Github\Project\Eropic\docs D:\Github\Project\_eropic_docs_bak
Move-Item D:\Github\Project\Eropic\README.md D:\Github\Project\_eropic_readme_bak.md
```

然后在 Android Studio 用 `D:\Github\Project\Eropic` 新建项目；首次 Sync 成功后把文档移回：

```powershell
Move-Item D:\Github\Project\_eropic_docs_bak D:\Github\Project\Eropic\docs
Move-Item D:\Github\Project\_eropic_readme_bak.md D:\Github\Project\Eropic\README.md
```

### 方案 B：先在默认目录新建，再整体搬（备选）

新建到 `D:\AndroidStudioProjects\Eropic`，Sync 通过后把全部内容（含隐藏的 `.gitignore`、`.idea`、`gradle`、`gradlew*`）搬到仓库：

```powershell
robocopy D:\AndroidStudioProjects\Eropic D:\Github\Project\Eropic /E /MOVE
```

> 不要把项目建到 `D:\Github\Project\Eropic\app` 这类子目录——Git 仓库根会错位，所有相对路径和文档都得改。

## 4. 向导参数（New Project 逐项）

1. 左侧 **Phone and Tablet** → **Empty Activity** → Next
2. **Name**：`Eropic`
3. **Package name**：`io.github.你的用户名.eropic`（全小写，不能有空格/连字符）
4. **Save location**：`D:\Github\Project\Eropic`
5. **Language**：`Kotlin`
6. **Minimum SDK**：`API 31: Android 12.0 (Snow Cone)`
7. **Build configuration language**：`Kotlin DSL (build.gradle.kts)`
8. Finish，等待 Gradle Sync（3~10 分钟，取决于网络）

> 若向导有 "Use version catalog" 选项，保持勾选（默认）。

## 5. Sync 失败排查（按顺序）

1. **Gradle JDK**：Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK，选 `Embedded JDK (jbr-21)` 或 `D:\jdk\jdk-17.0.12`。不要选 1.8/11。
2. **SDK 路径**：项目根 `local.properties` 应指向 `E:\Android\Sdk`（向导自动生成，**不提交**）。路径不对就在 SDK Manager 重设。
3. **缺 platform**：当前有 32/33/34/36、没有 35。若向导默认 35 而 Sync 报缺失，打开 SDK Manager 勾选 Android 15 (API 35) 与 Android 16 (API 36) 的 platform + build-tools。
4. **下载慢/超时**（国内常见）：报无法解析 `com.android.tools.build:gradle` 或下载 `gradle-8.x-bin.zip` 卡住。优先配代理（Settings → Appearance & Behavior → System Settings → HTTP Proxy），或临时用附录 A 的镜像。
5. **版本不匹配**：`Unsupported class file major version` → Gradle JDK 不对；`Minimum supported Gradle version is X` → wrapper 与 AGP 不匹配，改 `gradle/wrapper/gradle-wrapper.properties`（优先用缓存过的 8.13/8.14）。

## 8. AndroidManifest（M0 最小权限）

```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android">

    <!-- M0：只读图库 -->
    <uses-permission android:name="android.permission.READ_MEDIA_IMAGES" />
    <!-- Android 14+ 部分授权：必须声明并处理 -->
    <uses-permission android:name="android.permission.READ_MEDIA_VISUAL_USER_SELECTED" />
    <!-- 索引进度通知（M1 起用；先声明不影响安装） -->
    <uses-permission android:name="android.permission.POST_NOTIFICATIONS" />

    <application
        android:name=".EropicApplication"
        android:allowBackup="false"
        android:icon="@mipmap/ic_launcher"
        android:label="@string/app_name"
        android:roundIcon="@mipmap/ic_launcher_round"
        android:supportsRtl="true"
        android:theme="@style/Theme.Eropic">

        <activity
            android:name=".MainActivity"
            android:exported="true"
            android:theme="@style/Theme.Eropic">
            <intent-filter>
                <action android:name="android.intent.action.MAIN" />
                <category android:name="android.intent.category.LAUNCHER" />
            </intent-filter>
        </activity>
    </application>
</manifest>
```

M3 才加 `MANAGE_MEDIA` / `FOREGROUND_SERVICE*`；`MANAGE_EXTERNAL_STORAGE` 默认不加（ADR-0002）。
`allowBackup=false`：索引是可重建缓存，路径/回收站状态跨设备备份无意义；以后要备份设置再开。

## 9. MainActivity 骨架（4 Tab）

```kotlin
class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        setContent {
            EropicTheme {
                EropicApp()
            }
        }
    }
}
```

`EropicApp()` 结构：`Scaffold(bottomBar = { NavigationBar { ... } })` + `NavHost`，四个占位页 `GalleryScreen` / `FoldersScreen` / `CleanupScreen` / `MeScreen`。
注意把 `innerPadding` 传给内容，targetSdk 36 强制 edge-to-edge，否则列表会被系统栏遮挡。
完整代码在 M0 第一次提交里给；你当前只需让向导生成的 Hello World 能跑。

## 10. Git 初始化与首次提交

确认 Git 身份（只需一次）：

```powershell
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```

然后：

```powershell
cd D:\Github\Project\Eropic
git init
git add -A
git status   # 确认没有 local.properties、build/、.idea/
git commit -m "chore: scaffold Android project skeleton"
git branch -M main
git remote add origin https://github.com/<你的用户名>/Eropic.git
git push -u origin main
```

> 你的 GitHub 仓库是空的，直接 push 即可。若之前勾选了 README/License 导致远程有首个 commit，先 `git pull --rebase origin main --allow-unrelated-histories` 再 push，并把 README 冲突合并成一份。

建议历史：先提交当前 `docs/`（`docs: add project plan and dev docs`），再提交脚手架。

## 12. 你不需要做的事

- 不用单独安装 Gradle（wrapper 自带，缓存已有 8.13/8.14）
- 不用配 NDK（纯 Kotlin，无原生代码）
- 不用生成签名（debug 默认签名；发布签名 M4 再做）
- 不用手写 `.gitignore`（向导生成，按 §6 检查）
