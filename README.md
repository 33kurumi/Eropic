# Eropic

> 本地优先的个人图片与存储管理工具（Android 12+，M2 清理检索阶段）

手机里 120GB+ 的照片，系统相册看不全、管不了、清不掉。Eropic 想解决三件事：

- **看得全**：自建索引，精准展示所有目录的图片；文件夹可聚合子目录查看，显示数量与体积，支持多字段排序与缩放。
- **找得准**：在本地离线找出重复图片、相似图片、大文件、久远图片、截图、模糊图片；只做检索与对比，**删除决策永远交给用户**。
- **动得了真实文件**：移动、重命名作用于真实存储路径；删除先进回收站（默认 30 天），可一键恢复。

## 技术栈

Kotlin 2.0 · Jetpack Compose（Material 3）· Room · Paging 3 · Coil 3 · WorkManager · DataStore；DI 用轻量 `AppContainer` 手写装配（ADR-0007）。
数据来源：MediaStore 增量同步 + Room 可重建索引；去重：SHA-256 / dHash / pHash + 分桶倒排候选裁剪。
**不申请网络权限**，无账号、无上传、无统计。

## 状态与计划

- 当前：**M2 清理检索已跑通** —— 在图库 MVP 之上补齐：缩略图磁盘缓存（浏览不再解原图）、ContentObserver + 12h 周期自动同步、多选与批量收藏/分享；清理页六类入口（重复/相似/大文件/久远/截图/模糊）、组合筛选（大小/格式/时间/收藏）、分组浏览与双栏对比预览。全部只读，不做任何删除/移动
- 已确认：iQOO Neo8 / Android 15 / 120GB+ / 无 SD 卡；GitHub 开源 + 侧载，不上架；M0 只做图片；最低 Android 12；尽量兼容 ColorOS 等主流 ROM
- 里程碑：M0 可行性原型 1~2 周 → M1 图库 MVP 3~4 周 → M2 清理核心 3 周 → M3 文件/回收站 2~3 周 → M4 打磨 2 周（合计约 11~14 周）
- 下一步：M2 收尾 —— 保留建议（判据可切换、默认不勾选）、清理报告；之后 M3 真实移动与回收站（`MANAGE_MEDIA` 写权限 + 二次确认 + 30 天可恢复）

## 试跑（当前可用）

```powershell
# 构建（或直接用 Android Studio 的 Run）
.\gradlew.bat :app:assembleDebug

# 安装到手机（USB 调试已开）
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

打开后：
1. 授予「照片和视频 → 允许全部」（只选部分照片会导致图库看起来漏图，页面顶部会提示补授权）。
2. 图库 Tab 点「开始建立索引」→ 等索引进度走完（首次 10 万张量级需要几分钟，可中断，已算过的不会重算）。
3. 图库：右上角排序菜单、收藏筛选、列数/显示开关在「设置 → 外观」。
4. 点任意图片进入全屏查看器：双指缩放、双击放大、左右翻页，顶栏可收藏/看详情/分享。
5. 文件夹 Tab：目录树可展开收起，进入目录后可开「包含子文件夹」聚合查看。
6. 清理 Tab：顶部切换「重复 / 相似 / 大文件 / 久远 / 截图 / 模糊」六类候选；重复与相似分组点「对比预览」进入双栏对照；右上角「组合筛选」可按大小/格式/时间/收藏过滤。
7. 结果页/分组缩略图可长按进入多选，批量收藏、取消收藏、分享。
8. 全部只读：清理页不会删除或移动任何文件，写操作（回收站、真实移动）在 M3 接入。

若系统限制后台，请在本机电池设置里允许 Eropic 后台运行，否则大批量指纹计算可能被中断（可回来重试，已算过的不会重复）。
