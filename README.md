# Eropic

> 本地优先的个人图片与存储管理工具（Android 12+，M3 写操作阶段）

手机里 120GB+ 的照片，系统相册看不全、管不了、清不掉。Eropic 想解决三件事：

- **看得全**：自建索引，精准展示所有目录的图片；文件夹可聚合子目录查看，显示数量与体积，支持多字段排序与缩放。
- **找得准**：在本地离线找出重复图片、相似图片、大文件、久远图片、截图、模糊图片；只做检索与对比，**删除决策永远交给用户**。
- **动得了真实文件**：移动、重命名作用于真实存储路径；删除先进回收站（默认 30 天），可一键恢复。

## 技术栈

Kotlin 2.0 · Jetpack Compose（Material 3）· Room · Paging 3 · Coil 3 · WorkManager · DataStore；DI 用轻量 `AppContainer` 手写装配（ADR-0007）。
数据来源：MediaStore 增量同步 + Room 可重建索引；去重：SHA-256 / dHash / pHash + 分桶倒排候选裁剪。
**不申请网络权限**，无账号、无上传、无统计。

## 试跑（当前可用）

```powershell
# 构建（或直接用 Android Studio 的 Run）
.\gradlew.bat :app:assembleDebug

# 安装到手机（USB 调试已开）
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

打开后：
1. 授予「照片和视频 → 允许全部」（只选部分照片会导致图库看起来漏图，页面顶部会提示补授权）。
2. 图库 Tab 点「开始建立索引」→ 等索引进度走完（首次 10 万张量级需要几分钟，可中断，已算过的不会重算）。
3. 图库：右上角排序菜单、收藏筛选、列数/显示开关在「设置 → 外观」。
4. 点任意图片进入全屏查看器：双指缩放、双击放大、左右翻页，顶栏可收藏/看详情/分享。
5. 文件夹 Tab：目录树可展开收起，进入目录后可开「包含子文件夹」聚合查看。
6. 清理 Tab：顶部切换「重复 / 相似 / 大文件 / 久远 / 截图 / 模糊」六类候选；重复与相似分组点「对比预览」进入双栏对照；右上角「组合筛选」可按大小/格式/时间/收藏过滤；分组卡点「选择保留」按策略（体积最大/最小、拍摄最早/最新、路径最短）生成建议，确认后只移入回收站。
7. 结果页/分组缩略图可长按进入多选，批量收藏、取消收藏、分享；右上角「⋮」可「移动到文件夹…」或「移入回收站」（需先授权）。
8. 设置 Tab →「文件权限」点「去系统设置授权」，授予「所有文件访问」后写操作才可用；未授权时相关按钮置灰，浏览与查重不受影响。
9. 回收站 Tab：查看已删除项与剩余天数，可多选恢复或永久删除；清空/永久删除会二次确认；刚移入的会有 5 秒「撤销」。
10. 设置 Tab →「后台与电量」：可关掉「仅充电时补齐缩略图」和「启动时自动续算中断的索引」；索引被打断（退后台/被系统杀）不会丢已算结果。

若系统限制后台，请在本机电池设置里允许 Eropic 后台运行，否则大批量指纹计算可能被中断（可回来重试，已算过的不会重复）。
