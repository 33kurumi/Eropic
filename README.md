# Eropic

> 本地优先的个人图片与存储管理工具（Android 12+，v0.3 实测反馈版）

手机里 120GB+ 的照片，系统相册看不全、管不了、清不掉。Eropic 想解决三件事：

- **看得全**：自建索引，精准展示所有目录的图片；文件夹可聚合子目录查看，显示数量与体积，支持多字段排序与缩放。
- **找得准**：在本地离线找出重复图片、相似图片、大文件、久远图片、截图、模糊图片；只做检索与对比，**删除决策永远交给用户**。
- **动得了真实文件**：移动、重命名作用于真实存储路径；删除先进回收站（默认 30 天），可一键恢复。

## 技术栈

Kotlin 2.0 · Jetpack Compose（Material 3）· Room · Paging 3 · Coil 3 · WorkManager · DataStore；DI 用轻量 `AppContainer` 手写装配（ADR-0007）。
数据来源：MediaStore 增量同步 + Room 可重建索引；去重：SHA-256 / dHash / pHash + 分桶倒排候选裁剪。
**只在「识图 → 联网搜图」时联网**（点按那一刻上传你选中的那一张图）；无账号、无统计、不自动上传任何东西（ADR-0022）。

- 已明确推迟（不阻塞使用）：真机 10 万张基准（M0-7）、视频纳入图库（A-12）、类 PhotoPrism 高级筛选 DSL（B-19）、系统回收站后端（D-08）、同场景语义相似（CLIP）、后 4 个联网识图服务（TinEye/SauceNAO/IQDB/trace.moe 需 API key 或签名）、视觉细节打磨（等真机体验反馈）

## 试跑（当前可用）

```powershell
# 构建（或直接用 Android Studio 的 Run）
.\gradlew.bat :app:assembleDebug

# 安装到手机（USB 调试已开）；文件名带构建时间，换一个即可
adb install -r "app\build\outputs\apk\debug\Eropic-debug-0.3.0-<构建时间>.apk"
```

> APK 名字形如 `Eropic-debug-0.3.0-20261028-2052.apk`：带版本与构建时间，手机浏览器不会再把它和旧包当成同一个文件；`versionCode` 就是构建时间戳，装新包会直接覆盖旧包（不用卸载）。

打开后：
1. 授予「照片和视频 → 允许全部」（只选部分照片会导致图库看起来漏图，页面顶部会提示补授权）。
2. 图库 Tab 点「开始建立索引」→ 等索引进度走完（首次 10 万张量级需要几分钟，可中断，已算过的不会重算）。
3. 图库：右上角排序菜单（拍摄时间/文件名/大小/分辨率/格式）、收藏筛选；列数/显示开关在「设置 → 外观」。
4. 网格上**双指捏合**可临时调整列数（3~8 列，不回写设置）；按拍摄时间排序时会插入日期标题行——**点标题可折叠/展开**那一天；筛选行右侧「显示方式：按月」可切成**按日**或**不分组**。
5. 点任意图片进入全屏查看器：双指缩放、双击放大、左右翻页；顶栏「⋮」有幻灯片播放、设为壁纸、用系统相册打开、复制文件路径；「详情」里有原始 EXIF（机型/镜头/光圈/快门/ISO/GPS）。
6. 文件夹 Tab：右上角可切**列表 / 网格**两种布局；网格模式下每格是该目录的首张图封面，点进去下钻子目录，顶部面包屑可返回；进入目录后可开「包含子文件夹」聚合查看。
7. 清理 Tab：顶部切换「重复 / 相似 / 大文件 / 久远 / 截图 / 模糊 / 连拍 / 大图」八类候选（「大图」按分辨率，不是体积）；分组卡给出**质量综合评分**建议——A/B 双图并排，每张右上角有勾选框（默认勾选 = 建议移入回收站的那张，点一下可改），图上直接列「总像素 / 格式 / bpp / 时间 / 文件名 / 清晰度」逐项得分，组底部写明「为什么这么选」；组内「全选建议（N 张）」/「移入回收站（M 张）」，列表顶部还有汇总条「已选 N 张 / 全部按建议勾选 / 移入回收站」。右上角是清理报告与组合筛选；右上角垃圾桶进回收站。
8. 结果页/分组缩略图可长按进入多选：批量收藏、取消收藏、分享；右上角「⋮」可「重命名…」「复制到文件夹…」「移动到文件夹…」「移入回收站」（写操作需先授权）。批量重命名支持模板 `{date}_{n}`、`{name}`、`{ext}`、`{time}`，预览里冲突项标红。
9. 写操作过程中顶部会出现进度条，可**暂停/继续/取消**；结束后自动进「操作结果」页（成功/失败/取消/字节 + 失败原因），从这里可直达操作历史。
10. 设置 Tab →「文件权限」点「去系统设置授权」，授予「所有文件访问」后写操作才可用；未授权时相关按钮置灰，浏览与查重不受影响。
11. 回收站：从**清理 Tab 右上角垃圾桶**进入（不占底部 tab；识图占用了原来那个位置）。页内可看已删除项与剩余天数、多选恢复或永久删除、二次确认、刚移入的有 5 秒「撤销」；顶部「回收站位置」卡显示当前目录，可改成 `Pictures/.EropicTrash`、`DCIM/.EropicTrash` 或自定义相对路径。
12. 设置 Tab →「后台与电量」：可关掉「仅充电时补齐缩略图」和「启动时自动续算中断的索引」；索引被打断（退后台/被系统杀）不会丢已算结果。
13. 图库顶栏「⋮」/设置「更多页面」可进六个二级页：**搜索**（文件名/路径模糊搜，可保存当前条件）、**存储总览**（按格式/年份/目录统计与占比）、**操作历史**（逐条撤销移动/重命名/复制/回收站）、**文件夹管理**（扫出空目录、新建目录、批量删除空目录）、**清理报告**、**关于**（权限/数据位置/许可/崩溃日志）。
14. 设置 →「清理设置」可改回收站保留期（7/30/60 天/永久）和相似度档位（严格/标准/宽松，改档后需重新扫描分组）；「扫描范围」可跳过隐藏目录，排除目录支持「浏览选择目录…」用系统选择器直接挑。
15. 识图：底部 Tab 进「识图」（图库顶栏「⋮」也能进）。页面分两块——**本地识图**：选一张图（或从库内候选里挑）→ 按 dHash/pHash 距离找出相似图（显示相似度百分比），可用文件名关键词辅助过滤；**联网识图**：四家服务 Google Lens / Yandex / SauceNAO / ascii2d，点「识图」才会上传**这一张**并打开浏览器看结果。SauceNAO 需要免费的 API Key：去 saucenao.com 注册 → 复制 Key → 填到「设置 → 联网识图」；不填只影响 SauceNAO，其他三家照用。
16. 设置 →「文件权限」整卡可点进独立的权限说明页；授权后也可以从这里再跳系统设置**关闭**权限。所有"需要权限"的提示文字都可以点，直达授权页。

若系统限制后台，请在本机电池设置里允许 Eropic 后台运行，否则大批量指纹计算可能被中断（可回来重试，已算过的不会重复）。

## 换图标（用自己的图）

1. 准备一张**正方形**图片（建议 1024×1024，PNG；主体放在画面中间，自适应图标的外圈会被系统裁掉）。
2. 覆盖这一个文件：`app/src/main/res/drawable-nodpi/ic_launcher_user.png`（文件名不要改）。
3. 重新构建安装：`gradlew :app:assembleDebug`，桌面图标即变成你的图。

> 现在这张 PNG 是占位图（青绿照片卡）。自适应图标的三层在 `res/mipmap-anydpi/ic_launcher.xml`：background 仍是配色渐变，foreground 已指向这张 PNG，monochrome 仍用矢量剪影（Android 13+ 主题图标会用系统配色重绘，不会显示你的照片）。
