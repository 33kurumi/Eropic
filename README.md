# Eropic

> 本地优先的个人图片与存储管理工具（Android 12+，M4 打磨完成）

手机里 120GB+ 的照片，系统相册看不全、管不了、清不掉。Eropic 想解决三件事：

- **看得全**：自建索引，精准展示所有目录的图片；文件夹可聚合子目录查看，显示数量与体积，支持多字段排序与缩放。
- **找得准**：在本地离线找出重复图片、相似图片、大文件、久远图片、截图、模糊图片；只做检索与对比，**删除决策永远交给用户**。
- **动得了真实文件**：移动、重命名作用于真实存储路径；删除先进回收站（默认 30 天），可一键恢复。

## 技术栈

Kotlin 2.0 · Jetpack Compose（Material 3）· Room · Paging 3 · Coil 3 · WorkManager · DataStore；DI 用轻量 `AppContainer` 手写装配（ADR-0007）。
数据来源：MediaStore 增量同步 + Room 可重建索引；去重：SHA-256 / dHash / pHash + 分桶倒排候选裁剪。
**不申请网络权限**，无账号、无上传、无统计。

## 试跑（当前可用）

```powershell
# 构建（或直接用 Android Studio 的 Run）
.\gradlew.bat :app:assembleDebug

# 安装到手机（USB 调试已开）
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

打开后：
1. 授予「照片和视频 → 允许全部」（只选部分照片会导致图库看起来漏图，页面顶部会提示补授权）。
2. 图库 Tab 点「开始建立索引」→ 等索引进度走完（首次 10 万张量级需要几分钟，可中断，已算过的不会重算）。
3. 图库：右上角排序菜单（拍摄时间/文件名/大小/分辨率/格式）、收藏筛选；列数/日期分组/显示开关在「设置 → 外观」。
4. 网格上**双指捏合**可临时调整列数（3~8 列，不回写设置）；按拍摄时间排序时自动按月分组显示标题。
5. 点任意图片进入全屏查看器：双指缩放、双击放大、左右翻页；顶栏「⋮」有幻灯片播放、设为壁纸、用系统相册打开、复制文件路径；「详情」里有原始 EXIF（机型/镜头/光圈/快门/ISO/GPS）。
6. 文件夹 Tab：目录树可展开收起，进入目录后可开「包含子文件夹」聚合查看。
7. 清理 Tab：顶部切换「重复 / 相似 / 大文件 / 久远 / 截图 / 模糊 / 连拍 / 小图」八类候选；重复与相似分组点「对比预览」进入双栏对照；右上角「组合筛选」可按大小/分辨率/格式/时间/收藏过滤；分组卡点「选择保留」按策略生成建议，确认后只移入回收站；右上角可看「清理报告」（八类命中数与可释放合计）。
8. 结果页/分组缩略图可长按进入多选：批量收藏、取消收藏、分享；右上角「⋮」可「重命名…」「复制到文件夹…」「移动到文件夹…」「移入回收站」（写操作需先授权）。批量重命名支持模板 `{date}_{n}`、`{name}`、`{ext}`、`{time}`，预览里冲突项标红。
9. 写操作过程中顶部会出现进度条，可**暂停/继续/取消**；结束后自动进「操作结果」页（成功/失败/取消/字节 + 失败原因），从这里可直达操作历史。
10. 设置 Tab →「文件权限」点「去系统设置授权」，授予「所有文件访问」后写操作才可用；未授权时相关按钮置灰，浏览与查重不受影响。
11. 回收站 Tab：查看已删除项与剩余天数，可多选恢复或永久删除；清空/永久删除会二次确认；刚移入的会有 5 秒「撤销」。
12. 设置 Tab →「后台与电量」：可关掉「仅充电时补齐缩略图」和「启动时自动续算中断的索引」；索引被打断（退后台/被系统杀）不会丢已算结果。
13. 图库顶栏「⋮」/设置「更多页面」可进六个二级页：**搜索**（文件名/路径模糊搜，可保存当前条件）、**存储总览**（按格式/年份/目录统计与占比）、**操作历史**（逐条撤销移动/重命名/复制/回收站）、**文件夹管理**（扫出空目录、新建目录、批量删除空目录）、**清理报告**、**关于**（权限/数据位置/许可/崩溃日志）。
14. 设置 →「清理设置」可改回收站保留期（7/30/60 天/永久）和相似度档位（严格/标准/宽松，改档后需重新扫描分组）；「扫描范围」可跳过隐藏目录并排除指定目录。

若系统限制后台，请在本机电池设置里允许 Eropic 后台运行，否则大批量指纹计算可能被中断（可回来重试，已算过的不会重复）。
